# Atreides Agro

A **Atreides Agro** é uma distribuidora fictícia do agronegócio criada para este desafio.

A ideia é desenvolver uma plataforma que una **Engenharia de Dados, IA e geolocalização** para apoiar vendas, estoque e atendimento ao produtor rural.

## O que quero construir

O sistema deverá permitir que o cliente converse com um agente de IA, informe sua necessidade e receba opções com base em dados reais de:

* produtos
* preços
* estoque
* localização
* centros de distribuição

A IA não poderá inventar preço, estoque ou disponibilidade. Essas informações sempre deverão vir do sistema.

## Dados e mapas

Também quero explorar dados geográficos para responder perguntas como:

* qual unidade está mais próxima do cliente?
* onde existe estoque disponível?
* quais regiões possuem maior demanda?
* onde existe risco de falta de produto?

## Stack inicial

* Python
* FastAPI
* PostgreSQL + PostGIS
* Docker
* Polars
* Next.js

Todo o ambiente será executado com Docker.

## Estado atual

O projeto está começando pela arquitetura, documentação e preparação do ambiente.

Depois serão desenvolvidos os pipelines de dados, mapas, agente de IA e dashboards.

## Objetivo

Meu objetivo com este projeto é praticar Engenharia de Dados em um cenário mais próximo de um problema real de negócio, integrando dados, IA e inteligência geográfica.
