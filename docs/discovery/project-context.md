# Descoberta inicial

A Atreides Agro é uma distribuidora fictícia que transformará dados comerciais,
logísticos e geográficos em atendimento e decisões melhores.

## Restrições essenciais

- O ambiente completo deve rodar com Docker Compose.
- Dados de clientes, fazendas e operações serão sintéticos.
- Regras críticas pertencem ao backend, nunca ao LLM.
- A evolução será incremental, testada e documentada.
- Segredos são fornecidos por variáveis de ambiente.

O resultado da Fase 1 é uma API e um banco geoespacial saudáveis, reproduzíveis
e testáveis, formando a base para os primeiros domínios de negócio.
